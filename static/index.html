In Unraid, open the Portkeeper container’s Console and run this sign-in command. Follow the native account sign-in there; Portkeeper does not execute this command from the browser.

Paste only the authorization response requested by this sign-in flow. Never your password or an API key.
Model choices can be loaded without making a model request.
Test connection sends one short request and uses your allowance. Drafting runs with agent tools disabled in a workspace containing only public project material. Portkeeper’s separate test build checks packaging; it does not confirm gameplay.
Use a loopback or private LAN address that the Portkeeper server can reach.
A project's README and source take room. Use 32768 or more; Ollama's default is too small. On a 32 GB GPU such as an RTX 5090, a 30B-class coding model at 4-bit, for example qwen3-coder:30b or qwen2.5-coder:32b, fits with a 32K context. Larger contexts need more memory.
The key is saved only on the Portkeeper server and is never shown again.
What a model sees: the release's file list, the README and documentation, and short excerpts of the source code. Never your game files, their locations, or any token. Native agent tools are disabled.
